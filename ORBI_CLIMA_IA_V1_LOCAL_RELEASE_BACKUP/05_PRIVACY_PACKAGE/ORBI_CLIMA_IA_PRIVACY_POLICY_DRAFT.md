# ORBI Clima IA - Política de Privacidad

Política de Privacidad — Borrador

ORBI Clima IA respeta la privacidad del usuario. La app funciona sin cuenta, sin login, sin backend propio y sin nube para sus preferencias locales.

Datos usados:
- Ubicación aproximada o precisa solo si el usuario concede permiso para consultar el pronóstico.
- Preferencias locales de perfil, widgets, alertas y horarios.
- Memoria climática local de uso simple, como ubicaciones frecuentes confirmadas, perfil más usado y widget más usado.
- Historial local de alertas y notificaciones, limitado y controlable por el usuario.

Uso de datos:
Los datos se usan para mostrar clima, generar recomendaciones SkyCore, actualizar widgets, configurar alertas locales y mejorar la experiencia dentro del dispositivo.

Almacenamiento:
Las preferencias, memoria climática e historial local se guardan en el dispositivo mediante almacenamiento local. El usuario puede exportar, importar o borrar esta información.

Compartición:
ORBI Clima IA no vende datos del usuario. La app no requiere backend propio ni cuenta. Las consultas climáticas pueden enviarse al proveedor de pronóstico configurado, como Open-Meteo, para obtener datos meteorológicos de la ubicación solicitada.

Ubicación:
La ubicación se usa únicamente para consultar el pronóstico solicitado por el usuario. El guardado de ubicación GPS como preferida requiere confirmación explícita.

Notificaciones:
Las notificaciones son locales del dispositivo y se basan en alertas SkyCore generadas dentro de la app.

Limitaciones:
ORBI Clima IA no reemplaza servicios meteorológicos oficiales, alertas de emergencia, protocolos HSE ni evaluación profesional en terreno.
